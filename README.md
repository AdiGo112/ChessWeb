# ChessWeb

A web-based chess app: an Express server serving a browser chessboard built with [chessboard.js](https://chessboardjs.com/) and [chess.js](https://github.com/jhlywa/chess.js). This was an early prototype.

> **This project evolved into [AdiGo112/Wchess](https://github.com/AdiGo112/Wchess)**, real-time multiplayer chess with server-side clocks, ratings and game analysis. Development continues there.

## Run it

Requires Node.js.

```sh
npm install
npm start
```

Then open http://localhost:3000.
